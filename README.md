# Windows11Custom

Untuk direct edit windows kalian bisa ambil file yang Main_PC untuk editing iso kalian ambil file xml yang iso belakangnya jangan salah ambil.

Disni saya share untuk import file dari NTLite jika kalian butuh
Untuk yang game kalian butuh gamingtcui.dll untuk running seperti forza horizon 5 saya siapkan dll atau kalian bisa download dll di https://www.dll-files.com/gamingtcui.dll.html
dan kalian bisa copy paste direcly ke game location kalian.
untuk cara yang ke 2 kalian bisa copy gamingtcui.all ke C:\Windows\System32 kemudin buka powershell with admin dan paste command ini
regscr32 gamingtcui.dll
setelah itu bisa restart dan coba lagi game kalian.

Note : jangan hapus untuk embeded mode iot untuk windows 11 26H2 karena kalian bisa hilang untuk taksbar dan gabisa balik, atau untuk custom iso itu tidak bisa di hapus karena instalasinya akan error
